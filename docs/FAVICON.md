# Favicon

Generated with the built-in Imagegen tool. The original image is saved at `public/assets/brand/game-icon.png`. Next.js discovers `app/favicon.ico`, `app/icon.png` and `app/apple-icon.png` through its file conventions. The ICO contains 16, 32, 48 and 64 px variants. PNG variants are 256 px and 180 px. ImageMagick resizes use nearest-neighbour filtering to retain the pixel edges.

## Generation prompt

Use case: logo-brand. Asset type: favicon for the browser game Grand Theft Pokémon. Create one square 1024 by 1024 icon, flat chunky 16-bit pixel art. A single perfectly centered oversized capture-ball emblem on a near-black charcoal rounded-square tile. The ball has a red-orange upper half, warm ivory lower half, thick black horizontal belt and a small gold circular centre button. Strong pixel-stepped dark outlines, very limited colors, clear silhouette readable at 16 by 16 pixels. Use consistent large pixel blocks, generous but minimal padding, emblem fills about 80 percent of the tile. No letters, no text, no characters, no extra symbols, no photorealism, no gradients, no bevels, no mockup, no watermark. Only the area outside the tile's rounded corners is transparent.
